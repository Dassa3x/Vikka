VIKKA complete frontend, animation fix

1. Extract this ZIP inside your Vikka project folder. It contains a frontend folder.
2. Open Command Prompt inside the new frontend folder.
3. Run: npm install
4. Run: npm run dev
5. Refresh the Local URL shown by Vite (normally http://localhost:8443/).

The illustrated animation assets are already inside frontend/src/assets.
The handoff animation moves and rolls the carton across the campus, changing words in order. It runs even if the browser reports a reduced-motion preference.
If port 8443 is in use, close the earlier dev server with Ctrl+C.
